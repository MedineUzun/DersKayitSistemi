# DersKayitSistemi

A Windows Forms desktop application for managing course registrations, students, and teachers.

## Features

- **Admin Panel**: Manage students, teachers, and courses
- **Teacher Panel**: View students, manage courses, messaging
- **Student Panel**: Register for courses, view available courses, messaging
- User authentication system

## Technologies

- C# (.NET 7.0)
- Windows Forms

## Purpose

Built as a software lab project to practice Windows Forms development and multi-user system architecture.
